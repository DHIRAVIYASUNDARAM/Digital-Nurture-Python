# Python Module 2 Assignment

## Overview

This repository contains the solutions for **Python Module 2** as part of the **Digital Nurture Program**. The assignment demonstrates practical implementation of Python programming concepts ranging from basic syntax and data types to object-oriented programming, file handling, exception handling, and real-world application development.

The solutions are implemented in a Jupyter Notebook and showcase both foundational programming skills and problem-solving techniques using Python.
